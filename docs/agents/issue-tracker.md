# Issue Tracker — Daybook

Issues live in **GitHub Issues** on `fncreator22/Daybook-app`.

## CLI

Skills use the `gh` CLI for all issue operations:

```bash
gh issue create --title "..." --body "..." --label "needs-triage"
gh issue list --label "ready-for-agent"
gh issue edit 42 --add-label "ready-for-agent" --remove-label "needs-triage"
gh issue comment 42 --body "..."
gh issue close 42
```

## Conventions

- Every triaged issue carries exactly one **category** label (`bug` or `enhancement`) and one **state** label.
- AI-generated triage comments must begin with `> *This was generated by AI during triage.*`
- External PRs are **not** in the triage surface by default (PRs-as-request-surface flag: **off**).
- Issues created by `to-tickets` are opened with `needs-triage` until triaged.
